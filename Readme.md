# Automata Examples

collect some basic examples to use automata fsm engine into different runners:

## node

[node](./node)

run index.js file with node:

```sh
make -C node run
```

## deno

[deno](./deno)

run index.js file with deno:

```sh
make -C deno run
```

## html

[html](./html)

run python http.server module and open [localhost:8000](http://localhost:8000) into browser

```sh
make -C html run
```
